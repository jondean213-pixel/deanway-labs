# DeanWay Labs website

Static site for deanwaylabs.com, deployed on Netlify (original Netlify account — DeanWay Labs only; DeanWay Travels lives on its own separate Netlify account since Oct 31, 2026).

Permanent deploy path: this repo is linked to the Netlify site, so every push to `main` deploys automatically — no tokens, no renewals.

Contents: `index.html`, `styles.css`, `lab.js`, `netlify.toml`, `assets/`, and `netlify/functions/` (Lab Concierge chat, build log, inquiry).
